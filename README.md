# Firmups Documentation

This repository contains the documentation needed for the firmups project in regard to academical work. This project has been done as part of the Master in Cyber Security by Carlo Kirchmeier. 

## Technology
For this documentation [typst](https://typst.app) is used as technology to create reproducible document output. In order to build the documentation you need either one of the prebuilt binaries found on the typst webpage or alternatively the docker image or the Visual Studio code extension can be used to compile the documentation.
